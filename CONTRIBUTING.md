# Contributing

This page is the index for people who change this repository. Using the tool is
described in the [README](README.md) and in `docs/`.

- [docs/maintainers/development.md](docs/maintainers/development.md): layout,
  build, test, dependencies and self-policing CI.
- [tests/README.md](tests/README.md): test cases and canaries.
- [policy/README.md](policy/README.md): the merge policy and the required
  repository settings.
- [ci/README.md](ci/README.md): the check scripts, workflows and release files.
- [SECURITY.md](SECURITY.md): reporting a vulnerability privately.

Every change under `src/` needs approval by a code owner who did not write it.
The files that configure or run the checks (judge paths, see
[docs/change-control.md](docs/change-control.md)) need human approval.
